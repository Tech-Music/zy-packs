# zy 数据分卷

一组供**离线 HTML 页面**可选加载的数据分卷（`zy-*.js`）。把分卷与主网页放在同一个文件夹，网页会自动读取；也可以在网页内手动导入。网页不依赖本仓库即可运行，本仓库只用于补全扩展内容。

## 文件说明

| 文件 | 内容 |
|---|---|
| `zy-ext-1~3.js` | 扩展字库一级分卷（3 卷）：字条、读音、古文字字形、笔顺、多款字体 |
| `zy-ext2-1~3.js` | 扩展字库二级分卷（3 卷）：内容同上 |
| `zy-seal-1~4.js` | 篆体字体分卷（4 卷）：官方字体文件完整收录、原样分发（© 中央研究院，CC BY-ND 3.0 TW） |
| `zy-vox-1~5.js` | 语音分卷（5 卷）：扩展字读音、常用词与讲解朗读（神经网络语音合成，16 kbps） |
| `zy-download.bat` | 一键下载脚本：双击把全部分卷下载到所在文件夹（Windows 自带 curl），已存在的文件自动跳过 |

- 所有分卷均为**可选**：缺哪卷就少哪部分内容，网页本身不受影响。
- 文件名请勿修改；分卷请与主网页保持在**同一个文件夹**。
- 字形、字体与语音的来源及授权详见网页内"关于"页；署名信息同时保留在各分卷头注释中。

## 下载方式

1. **一键脚本**：下载 `zy-download.bat` 放到主网页所在文件夹，双击运行，失败重跑即可续传缺失分卷。
2. **整包**：仓库首页 → 克隆/下载 → 下载 ZIP，解压后把 `zy-*.js` 移到主网页同文件夹。
3. **单文件直链**：所有分卷均小于 10 MB，可匿名直链下载：
   `https://gitee.com/Geek-Leo/zy-packs/raw/master/zy-ext-1.js`（文件名可替换为任意分卷）
